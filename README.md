# WarMechForge

A free, unofficial fan-made 3D browser game of Classic hex-and-record-sheet 'Mech combat against an AI,
featuring the 'Mechs of the 2026 BattleTech Core Box.

Play: https://dragoonant.github.io/warmechforge/

**Unofficial fan project.** Not affiliated with or endorsed by Catalyst Game Labs, Topps or Microsoft.
BattleTech, 'Mech names and related marks belong to their respective owners. This project is free and
non-commercial; its art, text, sound and code are original.

## Develop

    npm install
    npm run dev
    npm test
