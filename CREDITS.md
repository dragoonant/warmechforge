# Credits

## Board ground and cliff textures

The hex board ground mats and cliff rock (`public/assets/terrain/boards/<theme>/`) are generated by `art/board-textures/gen.py`
from CC0 (public domain) 1k texture bases by Poly Haven (https://polyhaven.com), fetched by `art/board-textures/fetch.py`.
The generator de-tiles, blends and re-tints them; the outputs are our own derived art.

| Poly Haven asset | Used for |
|---|---|
| dry_ground_rocks | desert sand base |
| gravelly_sand | desert gritty ground |
| mud_cracked_dry_03 | desert cracked-earth patches |
| sandy_gravel_02 | desert pebble scatter |
| rock_face | cliff rock on terrace sides (both themes) |
| grass_path_3 | grasslands base |
| leafy_grass | grasslands base |
| brown_mud_dry | grasslands bare-earth patches |

The mat-generation helpers (FFT-noise de-tiling, layer blending) are adapted from our sibling game Whirr Machine.

## Game shop surroundings

| File | Source | Licence | Use |
|---|---|---|---|
| `public/assets/environment/shop-interior-1k.hdr` | Poly Haven "Small Empty Room 1" HDRI, 1k (https://polyhaven.com/a/small_empty_room_1) | CC0 (public domain) | soft reflections on the shop materials only (`scene.environment`); never shown as a backdrop |

Everything else in the shop (geometry, canvas textures, box art, posters, flyers, the shop name "The Crooked Die" and the drink
label) is procedural and original to this project. All names, brands and art are invented; none imitates a real product.

## 'Mech figures

The figure models in `public/assets/models/` and the concept and figure sheets in `art/unit-concepts/` and `art/figure-sheets/`
are our own generated art (image generation, then the local image-to-3D pipeline), made for this fan project. They are not
Catalyst Game Labs, Topps or Microsoft art.

## Code

Board, camera, presentation director, dice tray, frame-rate and test-hook patterns are adapted from our sibling game Whirr Machine.

## Map layouts

The hex layouts of the four Core Box maps (Headwater Crossing, Sodden Hills, Scorched Oasis, Arid Canyons) in `src/data/maps/`
were converted hex by hex (level, woods, rough, water, road) from the AGoAC board data of MegaMek's `mm-data`
(https://github.com/MegaMek/mm-data, CC BY-NC-SA 4.0, (C) The MegaMek Team). No board file is copied into this repository; each
map's `source` note names the file and commit checked.

## 'Mech and equipment numbers

Stock 'Mech stats (armor, engine, heat sinks, slot layouts) and the weapon, ammo and equipment numbers added in the roster batch
were read from MegaMek's `mm-data` MTF files and the MegaMek equipment classes (https://github.com/MegaMek/mm-data and
https://github.com/MegaMek/megamek, mm-data CC BY-NC-SA 4.0, (C) The MegaMek Team) and typed in by hand as cross-checks against
the Core Box brief. No MegaMek file is copied into this repository; each record's `source` note names what was checked.
Battle Values come from the Master Unit List.
The ferro-lamellor damage cut was checked against MegaMek's `TWDamageManager` (https://github.com/MegaMek/megamek, GPL v3); our code is our own.
